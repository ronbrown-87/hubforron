# Norum's Hub Portfolio

Build a high-converting, modern, single-page business portfolio website for "Norum'sHub" (Tagline: Programmer / Designer / Creative).

### Brand Identity & Aesthetics:
- **Logo:** Use the uploaded logo image in the header/navbar and hero section. 
- **Color Palette:** Modern dark mode aesthetic matching the logo. Primary background: Deep Navy/Slate (`#0B1320`), Primary Accent: Electric Cyan Gradient (`#00D2FF`), Secondary Accent: Deep Royal Blue (`#2563eb`), Text: Crisp White and Cool Slate (`#94a3b8`).
- **Styling:** Glassmorphism card elements, clean Tailwind CSS layout, Lucide React icons, and subtle hover animations on interactive elements.

### Navigation Header:
- Sticky navigation bar with the Norum'sHub logo on the left.
- Section navigation links: [Services, Portfolio, Work Process, Trust Wall, Contact].
- Right CTA Button: High-visibility cyan gradient button labeled "Get a Quote".

### Section 1: Hero Section
- **Headline:** "Transforming Ideas into High-Performance Web Apps & Striking Brand Identities."
- **Subheadline:** "Full-stack programming, modern UI/UX design, and complete visual branding for ambitious businesses."
- **CTAs:** Dual buttons — "Explore Portfolio" (scrolls to gallery) and "Start a Project".
- Include a sleek floating badge: "Available for New Projects & Freelance Deals".

### Section 2: Core Services (Grid Layout)
Create 4 distinct service cards with icons:
1. **Web & Software Development:** Full-stack web applications, landing pages, API integrations, and responsive React/Tailwind interfaces.
2. **Brand & Logo Design:** Custom logo design, brand guidelines, visual identity systems, and vector assets.
3. **Print & Digital Graphics:** High-resolution business cards, flyers, event posters, and promotional materials.
4. **Corporate Documents:** Professional company profiles, project proposals, and executive document layouts.

### Section 3: Dynamic Work & Portfolio Showcase (Interactive Filterable Gallery)
- **Category Filter Tabs:** [All, Web Apps, Branding & Logos, Business Cards & Flyers, Company Profiles].
- **Project Cards:**
  - High-quality image or live mockup preview.
  - Project Title, Description, and Tech/Tool Badges (e.g., React, Supabase, Graphic Design, PDF Design).
  - Interactive Action Buttons:
    - "Live Preview" or "View Design" button.
    - Interactive **"Grateful Badge" (Heart/Clap Button)** with a live tap counter so visitors and clients can appreciate completed projects.

### Section 4: Client Onboarding & Binding Agreement Download
- **Title:** "How We Work Together (Step-by-Step Process)"
- **Process Steps:** 
  1. Discovery & Requirement Gathering
  2. Proposal & Binding Agreement
  3. Design & Code Execution
  4. Final Review & Launch
- **Featured Download Card:** "Norum'sHub Service Guide & Agreement (PDF)".
  - Add a dedicated download button giving clients an overview of services and a binding agreement template featuring a dual-signature block (Creative & Client signature spaces) to formalize business deals.

### Section 5: Trust Wall & Verified Reviews
- Grid showcasing client feedback, star ratings, and visual **"Verified Deal"** badges to demonstrate reliability and build client confidence.
