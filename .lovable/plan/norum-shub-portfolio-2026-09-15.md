# Norum'sHub Portfolio

## Goal
Build a polished, conversion-focused single-page portfolio for Norum'sHub using the supplied logo, dark navy styling, cyan-to-blue accents, glass surfaces, and restrained motion.

## Build
- Clean the supplied logo by removing the Gemini badge, then use the corrected artwork in the sticky header and hero.
- Create a responsive one-page experience with the requested navigation, hero copy, availability badge, and quote/project calls to action.
- Add four service cards, a filterable project gallery with representative project visuals, tool badges, preview actions, and working appreciation counters.
- Add the four-step work process and a featured downloadable Norum'sHub Service Guide & Agreement PDF with service overview, agreement terms, and Creative/Client signature spaces.
- Add a verified review wall, direct contact details, WhatsApp/email actions, and a validated contact form with clear success feedback.
- Finish with a compact branded footer and working section/social links.

## Visual Direction
- Deep navy/slate foundation with electric cyan and royal blue accents, crisp white type, and cool slate supporting text.
- Professional glass panels, sharp information hierarchy, subtle glow, restrained hover/entry motion, and accessible contrast.
- Use the brand artwork as the first visual signal while keeping every section readable and conversion-focused on mobile and desktop.

## Technical Details
- Implement in the existing TanStack Start/React app with Tailwind v4 semantic design tokens and Lucide icons.
- Keep interactions client-side: gallery filtering, appreciation counters, navigation scrolling, and form validation.
- Generate and visually inspect the downloadable PDF before linking it from the site.
- Add route-specific metadata and verify the finished page at desktop and mobile sizes.
